# SkyStore - Интернет-магазин цифровых продуктов

SkyStore - это платформа для продажи и хранения цифровых продуктов: плагинов, примеров кода, веб-приложений и микросервисов.

## 🚀 Возможности проекта

- 📦 Каталог цифровых продуктов с описанием и ценами
- 📞 Страница контактов с формой обратной связи
- 📱 Адаптивный дизайн (мобильная версия)
- 🎨 Современный интерфейс на Bootstrap 5
- 🔒 Защита от CSRF атак
- 📝 Валидация форм на сервере

## 🛠 Технологический стек

- **Backend:** Django 6.0.1
- **Frontend:** HTML5, CSS3, Bootstrap 5
- **База данных:** SQLite (для разработки)
- **Язык программирования:** Python 3.11+

## 🚀 Установка и запуск

### 1. Клонирование репозитория

```
git clone <repository-url>
cd hw_online_store
```

### 2. Создание виртуального окружения

```
python -m venv .venv
```

### 3. Активация виртуального окружения

Windows:
```
.venv\Scripts\activate
```

macOS/Linux:
```
source .venv/bin/activate
```

### 4. Установка зависимостей

```
pip install -r requirements.txt
```

### 5. Запуск сервера разработки

```
python manage.py runserver
```

### 6. Открытие в браузере

Перейдите по адресу: http://localhost:8000

### 🌐 Доступные страницы

- ***Главная страница***: / - каталог продуктов
- ***Контакты***: /contacts/ - страница с контактной информацией и формой обратной связи

### 📝 Форма обратной связи

На странице /contacts/ реализована форма обратной связи с валидацией:
- Проверка заполнения всех обязательных полей
- Вывод сообщений об успешной отправке
- Защита от CSRF атак
