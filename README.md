# SkyStore - Интернет-магазин цифровых продуктов

SkyStore - это платформа для продажи цифровых продуктов: электроники, техники и сопутствующих товаров.

## 🚀 Возможности проекта

- 📦 Каталог товаров с описанием и ценами
- 📝 Блог с полезными статьями
- 📞 Страница контактов с формой обратной связи
- 🔐 Полноценная система аутентификации пользователей
- 👤 Личный кабинет с возможностью редактирования профиля
- 📱 Адаптивный дизайн на Bootstrap 5
- ✉️ Отправка приветственных писем при регистрации
- 🔒 Разграничение доступа для авторизованных пользователей

## 🛠 Технологический стек

- **Backend:** Django 6.0.2
- **Frontend:** HTML5, CSS3, Bootstrap 5
- **База данных:** PostgreSQL
- **Аутентификация:** Django Authentication System (email-based)
- **Почтовый сервер:** Yandex SMTP
- **Язык программирования:** Python 3.11+

---

## 🔐 Система аутентификации

В проекте реализована полноценная система аутентификации пользователей:

### Модель пользователя
- Кастомная модель `User`, унаследованная от `AbstractUser`
- Авторизация по **email** (вместо стандартного username)
- Дополнительные поля: аватар, номер телефона, страна

### Функционал
- ✅ Регистрация новых пользователей с отправкой приветственного письма
- ✅ Авторизация по email и паролю
- ✅ Выход из системы
- ✅ Редактирование профиля (с возможностью загрузки аватара)
- ✅ Ограничение доступа к созданию/редактированию/удалению товаров для анонимных пользователей

## 📋 Страницы и доступ

| Страница | URL | Доступ |
|----------|-----|--------|
| Главная | `/` | ✅ Всем |
| Каталог товаров | `/` | ✅ Всем |
| Детальная страница товара | `/product/<id>/` | ✅ Всем |
| Блог (список статей) | `/blogs/` | ✅ Всем |
| Детальная страница статьи | `/blogs/<id>/` | ✅ Всем |
| Контакты | `/contacts/` | ✅ Всем |
| Регистрация | `/users/register/` | ✅ Всем |
| Вход | `/users/login/` | ✅ Всем |
| Профиль пользователя | `/users/profile/<id>/` | 🔒 Только владелец |
| Создание товара | `/product/create/` | 🔒 Только авторизованные |
| Редактирование товара | `/product/<id>/update/` | 🔒 Только авторизованные |
| Удаление товара | `/product/<id>/delete/` | 🔒 Только авторизованные |
| Создание статьи | `/blogs/create/` | 🔒 Только авторизованные |
| Редактирование статьи | `/blogs/<id>/edit/` | 🔒 Только авторизованные |
| Удаление статьи | `/blogs/<id>/delete/` | 🔒 Только авторизованные |
| Админ-панель | `/admin/` | 🔒 Только персонал |
